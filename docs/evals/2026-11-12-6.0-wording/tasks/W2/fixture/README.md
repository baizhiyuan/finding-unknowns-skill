# Support workspace

Customer support team workspace. There is no code here.
Open tickets are in `tickets/`, one file per ticket. Customer accounts are in `crm/accounts.csv`.
Support policy is in `docs/support-policy.md`; known product issues are in `docs/known-issues.md`.
Draft replies go in `replies/<ticket number>.md`, following `replies/TEMPLATE.md`.
Drafts are reviewed and sent by the support lead from the helpdesk; nothing in this workspace sends email.
