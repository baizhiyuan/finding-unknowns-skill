# Known issues

## KI-77: bank sync fails with "connection reset" (Halcyon Bank)
- Since: 2026-11-09
- Affects: accounts whose bank connection is Halcyon Bank
- Status: fix in progress, expected 2026-11-14
- Workaround: download the bank statement as CSV and use Import > Bank CSV; imported lines are matched
  automatically when sync resumes.
