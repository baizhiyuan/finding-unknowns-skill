**Cause.** `report.sql` is fine. The bug was the date passed into it.
- The cron job runs at 00:30 Asia/Shanghai, but `CRON_TZ` only controls when cron fires.
- The container has `ENV TZ=UTC`, so Python's `date.today()` uses the UTC date.
- At 00:30 Tuesday in Shanghai it's still Monday 16:30 UTC. `yesterday()` therefore returned Sunday.

**Fix.** In `dates.py`, `yesterday()` now computes the date in a fixed UTC+8 business timezone instead of the container's timezone.

The weekly report had the same problem and is fixed by the same change. Before the fix its window ended on Saturday instead of Sunday.
