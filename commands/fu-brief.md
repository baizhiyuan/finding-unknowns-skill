# fu-brief

## Dispatch

1. With `--structured`, load `references/structured.md` first. It adds quadrant routing
   and the eight numbered techniques, and offers Cartographer at high stakes. Phase 0 and
   Techniques 1–5 run inside the Brief (step 2); Technique 5's Definition of verified
   becomes the card's contract. Record `Structured: yes` on the card.
2. Invoke the `finding-unknowns` skill with the Skill tool and run its **/fu-brief** steps:
   ship mode unless the person asks to learn; the person's prediction first (their
   prior); the territory, using the instruments in `references/brief.md` as the gap needs;
   then the agent's prediction; the Brief (approach with one-line whys, both sides'
   predictions, the four stop-points with a budget multiple, the contract); freeze on the
   person's yes and commit per `references/card.md`.
3. If an open card already covers this task, offer to continue it instead (`/fu-catch-up`).
4. Then build quietly: stop only at the four stop-points; log everything else on the card.
   Each turn ends with a completion report or a stop-point request.
